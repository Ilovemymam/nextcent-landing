Nextcent: адаптивный лендинг

Верстка лендинга по макету из Figma.Работает на декстопе, планшете и телефоне.
Посмотреть сайт: https://ilovemymam.github.io/nextcent-landing/

Что сделано
-Адаптивная вёрстка(декстоп, планшет, телефон)
-Бургер-меню для телефона
-Карточки, сетки статистики, блок блога
-Кнопки с анимацией при наведении

Технология, используемые в проекте:
HTML,CSS и чуть-чуть JavaScript
